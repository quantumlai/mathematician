# 恐龍博物館

幫小學生提升學習興趣的小遊戲：完成數學練習就能挖到恐龍化石，把骨頭拼成自己想像的恐龍，放上展示台，蓋一座自己的博物館。純 HTML / JavaScript，不需要安裝或建置。

## 玩法

- **登入**：輸入玩家代號（不用密碼）。第一次來要選年級（目前只有小三(上)）和角色；再次登入會顯示原本的年級，可以修改。玩家代號「寬爸」的博物館就叫「寬爸的恐龍博物館」。
- **採集新化石（數學）**：依玩家的年級出 10 題數學練習，每答一題馬上知道對錯。每題都可以打開「📝 計算紙」（原子筆、橡皮擦、清除），在 iPad 上用手指或觸控筆算。做完 10 題會列出每一題的答案與正確答案，還能打開那一題的計算紙檢查；離開練習後計算紙就不保留。答對 8 題以上得到一塊新骨頭：先補齊已經有的恐龍還缺的骨頭，都齊了才開始收集下一組。博物館大廳和編輯模式都有這個按鈕。
- **選單**：點左上角「☰ 寬爸的恐龍博物館（小三）」打開選單：「📊 我的成績單」（完成幾題數學、答對率、挖到幾次化石、最近 5 次練習）、「🎭 更換角色」、「＋ 新展台」、「🚪 登出」。
- **角色**：小小古生物學家、可愛小女生、猴子、兔子、獅子、劍齒虎、鸚鵡、機器人。博物館門口站著館長（主人的角色）；參觀別人的博物館時，自己的角色會在畫面左下角跟著逛。
- **博物館**：每個展台上擺著玩家拼好的化石（不管拼成什麼樣子，都會自動縮放、站在檯面上）。展台變多時大廳會往右延伸，可以拖曳、用滾輪或 ← / → 鍵左右參觀。
- **參觀其他博物館**：從清單進入其他玩家的博物館，只能看、不能改。
- **編輯模式**：點展品下方的「✏️ 重新組裝」，或「＋ 新展台」（從空的工作台開始），就會進入工作台擺骨頭、換展示台、改名字。按「儲存」回到博物館；「取消」會放棄這次的修改；「拆除展台」會把整個展台移除。
- **化石庫是有限的**：每一組素材各自一個分類，例如暴龍 (1)、暴龍 (2)，暗暗的是還沒採集到的骨頭。每塊骨頭整座博物館只能用一次，用過的會變淡；同一個展台可以混用不同組、不同恐龍的骨頭。收回骨頭或拆除展台會還回化石庫。
- **展示台不限數量**，每個展台都可以自由換。

## 開啟遊戲

- **最簡單**：直接雙擊 `index.html`。
- **建議**：用本機伺服器開啟，點骨頭的透明空隙時可以點到下面的骨頭，化石也會更準確地站在展示台上（直接雙擊開啟時，瀏覽器不讓程式讀取圖片像素，只能用骨頭的外框來判斷）。
  - VS Code 安裝 Live Server 擴充功能，對 `index.html` 按右鍵 →「Open with Live Server」，或
  - 在專案資料夾執行 `python -m http.server 8000`，再開 <http://localhost:8000>

## 玩家資料

玩家資料（年級、擁有的骨頭、展台、練習紀錄）由 `js/store.js` 存放，目前存在**這台電腦的瀏覽器**裡（localStorage）：

- 只有用同一台電腦、同一個瀏覽器的玩家，才看得到彼此的博物館。換電腦或換瀏覽器不會帶過去。
- 清除瀏覽器資料會讓所有玩家的博物館消失。
- 要讓不同電腦的玩家互相參觀，需要一個共用的存放位置。只要換掉 `js/store.js`、提供同樣的方法（`get`、`list`、`save`、`isEmpty`、`idOf`，都回傳 Promise），遊戲其他部分不用改。

還沒有玩家代號以前的舊存檔，會在建立第一個玩家時交給他，連同當時擁有的暴龍 2 組素材。

## 恐龍素材

素材建議用 **SVG**（放大不會模糊），也可以用已經去背的 PNG。

暴龍的 8 塊骨頭是 SVG，由 `tools/draw_trex.py` 產生（只需要 Python，不用額外套件）。要調整形狀、顏色，改這支腳本後重新執行：
```
python tools/draw_trex.py
```
8 塊骨頭用同一個比例尺繪製，`js/fossils.js` 裡的 `scale: 0.8` 讓它們放進展場時維持彼此的大小比例。

### 新增恐龍

1. 在 `assets/fossils/` 底下為新恐龍建立資料夾，例如 `assets/fossils/stegosaurus/`，放入每塊骨頭的 SVG。
   根元素要有 `width`、`height` 屬性，畫布請貼齊骨頭（不留大片空白），選取框才會貼合。可以參考 `tools/draw_trex.py` 的畫法再寫一支。
2. 在 `js/fossils.js` 加一筆：
   ```js
   {
     id: 'stegosaurus',
     name: '劍龍',
     scale: 0.8,   // 選填：骨頭用同一比例尺畫時才設定；不設定則每塊縮放到差不多大
     parts: [
       { id: 'skull', name: '頭骨', src: 'assets/fossils/stegosaurus/skull.svg' },
       { id: 'plates', name: '背板', src: 'assets/fossils/stegosaurus/plates.svg' },
     ],
   },
   ```
   `id` 會用在存檔裡，加入後請不要再改，否則玩家已擺好的那塊骨頭會消失。

加入後，數學練習的獎勵就有機會出現新恐龍（玩家已經有的恐龍都收齊時，會從組數最少的恐龍開始下一組；完全沒有化石的新玩家會隨機拿到一種）。

## 數學題庫

題庫在 `js/math/`，一個年級一個檔案。目前只有 `grade3a.js`（小三(上)），涵蓋 10000 以內的數、四位數加減、乘法、除法（含餘數）、公分與毫米、時間、分數，以及兩步驟應用題。每題的數字都是隨機產生，一次練習會從不同單元抽 10 題。

- **新增題型**：在 `topics` 加一個函式，回傳題目、答案和正確答案的說明（格式寫在檔案開頭）。題目裡的 `[[3/8]]` 會顯示成分數。
- **新增年級**：複製 `grade3a.js` 改成新年級（換掉 `id`、`name`、`short`、題目），在 `index.html` 加一行 `<script>`，登入畫面就會出現新的年級選項。
- 過關門檻（答對 8 題）在 `js/game.js` 的 `QUIZ_PASS`。
- 分數題接受等值分數（例如答案是 8 分之 4，寫 2 分之 1 也算對）。

## 角色

角色的圖在 `js/role.js`，每個角色是一個函式，回傳 SVG 字串（畫布 220×320，身體中心在 x=100），表情有 `normal` 和 `happy`。檔案最後的 `window.CHARACTERS` 是可以選的角色清單：

```js
{ id: 'robot', name: '機器人', svg: robotSVG },
```

新增角色：畫一個新的函式，再加進清單。`id` 會存在玩家資料裡，加入後請不要再改；找不到的角色會用清單第一個。SVG 裡不要用固定的 `id`（漸層、圖樣等），同一個畫面可能同時畫好幾個角色。

## 登入畫面的範例展品

登入畫面背後的兩件展品寫在 `js/showcase.js`，格式和玩家的展品一樣。

## 展示台素材

展示台放在 `assets/pedestals/`，清單在 `js/pedestals.js`。新增一種展示台：

1. 畫一張 SVG（或去背 PNG），寬度約 400～600 px，畫布貼齊展示台。博物館裡會用原始尺寸顯示。
2. 在 `js/pedestals.js` 加一筆：
   ```js
   { id: 'gold', name: '黃金展示台', src: 'assets/pedestals/gold.svg', surface: 16 },
   ```
   `surface` 是檯面距離圖片上緣幾 px，化石會站在這條線上。`id` 會用在存檔裡，加入後請不要再改。清單第一筆是新展台的預設展示台。

## 檔案結構

| 路徑 | 說明 |
| --- | --- |
| `index.html` | 頁面結構 |
| `css/style.css` | 樣式（登入、博物館大廳、工作台、化石庫、數學練習） |
| `js/fossils.js` | 化石素材清單 |
| `js/pedestals.js` | 展示台素材清單 |
| `js/showcase.js` | 登入畫面的範例展品 |
| `js/math/grade3a.js` | 小三(上) 數學題庫 |
| `js/store.js` | 玩家資料的存放（目前是瀏覽器 localStorage） |
| `js/quiz.js` | 數學練習畫面、做完後的回顧 |
| `js/scratchpad.js` | 計算紙 |
| `js/role.js` | 角色與場景的 SVG 美術；`CHARACTERS` 是玩家可以選的角色 |
| `js/game.js` | 遊戲邏輯：登入、博物館大廳、參觀、編輯模式、骨頭獎勵 |
| `assets/fossils/t-rex/*.svg` | 暴龍 8 塊骨頭 |
| `assets/pedestals/*.svg` | 展示台（木頭、大理石、岩石） |
| `tools/draw_trex.py` | 產生暴龍 SVG 的腳本 |
